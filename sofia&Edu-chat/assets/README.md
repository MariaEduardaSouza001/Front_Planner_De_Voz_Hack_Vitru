# Assets

Coloque aqui os arquivos opcionais de imagem:

- `sofia.png` — foto/ilustração da Sofia (usada no header, no menu e na tela de chat fechado).
- `logo.png` — logo da marca, exibida na tela de chat fechado.

Os dois são **opcionais**. Se um arquivo não existir, a interface remove o `<img>`
automaticamente e usa o avatar em SVG desenhado no próprio HTML, que acompanha a
cor do tema selecionado (Vitru / UNIASSELVI / UniCesumar).
